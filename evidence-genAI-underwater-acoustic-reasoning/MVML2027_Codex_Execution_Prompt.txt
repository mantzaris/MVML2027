5. LEARNED EVIDENCE ACQUISITION

Initial state: 32 PCA components of the acoustic embedding (PCA fitted on acoustic-fit), five calibrated class probabilities, entropy, simple signal quality, selected-action mask, and only observed tool numeric fields. Train feature normalization on training data. Truly mask unavailable values. No test-reference information or unrequested cached tool result may enter the state.

For each of 240 annotated policy-fit clips, generate the frozen terminal response for all 16 subsets S of the four tools. Similarly cache up to 16 subsets for each of 60 development and 60 calibration clips. Initial total is 3,840 + 960 + 960 = 5,760 reports. Preserve raw JSON/text, parsing status, tool versions and full cache keys: waveform hash, model revision, precision, prompt hash and subset. Evaluate against independent annotations, never against the tool's own output alone.

For an identifiable physical slot j:
  loss_j = 0 if correct and supported;
           1 if incorrect or unsupported;
           rho=.25 for abstention/omission.
For an independently ambiguous physical reference:
  loss_j = 0 for explicit uncertainty;
           rho for omission;
           1 for a categorical assertion.
For vessel class: 0 correct, 1 incorrect, rho abstain.

Define:
  L(S) = .5 * loss_class(S) + .5 * mean_j(loss_physical_j(S))
  Delta(S,a) = L(S) - L(S union {a})

This intervenes on available evidence, not on an ocean source. Rationale errors are separately audited, so do not claim the scalar loss evaluates all prose. A correct uncertain response is appropriate abstention and is not a positive physical fact in coverage metrics.

Train a three-member source-group bootstrap ensemble of MLPs with hidden widths 64 and 32, dropout .1, predicting terminal L(S) and four candidate deltas. Mask already observed actions in the delta loss. Use Huber regression, AdamW LR 1e-3, weight decay 1e-4, max 100 epochs and patience ten on development. All subset rows for a clip remain together. Bootstrap source groups rather than subset rows. Run independent controller ensembles with seeds 17,29,43; derive member seeds deterministically. These are not three independent end-to-end generator studies.

Choose the next available action maximizing:
  score(a) = mean_delta(a) - beta * sd_delta(a) - lambda * cost(a)

Initial beta=.5, lambda=.02; select beta in {0,.5,1}, lambda in {0,.02,.05} on development only. Primary cost(a)=1 counts tool calls. A secondary cost model can use pilot-measured latency. Ensemble spread is a heuristic, not a proven confidence bound.

Primary maximum budget B=2; B=1 and B=3 are sensitivity runs. Stop acquisition if no available action has positive adjusted gain or budget is exhausted. Update state using the acquired result before selecting another action. This observation-dependent second decision is the agent behavior that must be tested.

For offline evaluation, generate exactly one terminal report for every clip and save its predicted terminal risk before rejection. This permits fair coverage curves with no missing high-risk outputs. Fit a rejection threshold on calibration targeting 70% report coverage, and report actual test coverage. Separately report descriptive fixed-coverage test curves. Deployment can skip the generator above the threshold, but do not confuse this projected saving with measured offline costs. Give matched selectors the same risk head, structural checker and calibration opportunity.

Pseudocode:
  state = initial_state(audio)
  selected = {}
  while len(selected) < B:
      risk, mean_delta, spread = controller(state)
      action = best_available_adjusted_gain(mean_delta, spread)
      if action is none or adjusted_gain(action) <= 0: break
      evidence = execute(action, audio, acoustic_fit_bank)
      selected.add(action)
      state = update_observed_state(state, evidence)
  report_risk = shared_risk_head(state)
  raw_report = frozen_generator_once(audio, prior, selected_evidence)
  save_raw_and_checked_report(raw_report, report_risk)
  report = apply_calibration_threshold(raw_report, report_risk)

DSP tools may cost much less than one generative pass. Do not claim GPU savings merely from fewer DSP calls. Measure evidence/context efficiency, planner overhead and actual latency separately.
