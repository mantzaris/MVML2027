# Supplementary test of untrained vessel categories

This exploratory check was added after the fresh five-category results were available. It does not change the primary hypothesis, fitted models, score, thresholds, or success decision. Its question is whether the fixed identification/referral rules assign one of the trained categories to recordings from other explicit vessel categories in the release.

Use pilot vessel, rescue, sailing, pleasure craft, fishing and dredger; exclude the ambiguous catch-all `other`. These are held-out dataset categories, not a claim that their acoustic signatures are necessarily separable from trained vessel types. No representation or threshold is fitted on them. Apply the same source, whole-day and 60-second separation from all original fitting/selection/calibration data, and exclude source groups in both the original experiment and the fresh five-category cohort. Request 15 clips/category using the existing deterministic source-first sampler, at most three/source and ten minutes apart; retain shortfalls. Record source counts, particularly the single eligible pilot-vessel source.

Verify archive CRCs and decoded uniqueness against both earlier cohorts. Freeze the exact selected manifest, this note and the evaluation script before inference on these recordings. The already-frozen five-class study supplies all model parameters and reporting thresholds. Report, for every method, the count automatically assigned a trained category, the count referred, and the fraction recognized broadly as vessel versus background using the already selected binary threshold. Automatic trained-category assignments are out-of-vocabulary failures under the release taxonomy; they are not independent expert judgments about physical sound similarity. A generic background decision does not constitute correct recognition of these vessel recordings. Broad vessel recognition and referral are separate, potentially overlapping outcomes.

Report all six categories and all pre-existing methods without selecting an advantageous subset. This small, same-collection challenge does not establish open-world reliability. No additional generator training, human annotation or deployment claims are involved. Preserve results locally outside Git where large; stay within the original GPU deadline and leave the Pod running.
