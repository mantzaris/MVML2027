## Candidate novelty and necessary controls

Propose **nuisance-matched candidate-interval replacement as a cross-representation verification statistic that guides adaptive detection**, using a generative controller to select the next transform or verification action under a GPU budget. Controlled source insertion provides a separate validation experiment. Interval replacement is not source-selective deletion unless preservation of overlapping sources is demonstrated. This is a candidate contribution beyond static LLM fusion, report generation or generic augmentation. Do not claim “first” without a broader search. LLMs combined with underwater physics, complementary spectral evidence, parameterized synthetic data, and real-background mixtures are already present in the closest predecessors. Our bounded simulator is not a replacement for their richer array/propagation modeling.

Fourier, STFT, HHT and wavelet views share one waveform; agreement is not independent evidence. Generative edits are model-based interventions, not causal ground truth. Measure reconstruction fidelity, unintended background changes and sham-edit effects. Compare against fixed fusion, fixed verification, a non-language controller, augmentation-only generation and equal-compute policies. Keep untouched real detection separate from synthetic/semi-synthetic interval localization; mixing recordings does not create real multi-source ground truth.

## Availability and label limitations

[DeepShip's author repository](https://github.com/irfankamboh/DeepShip) provides partial data; [ShipsEar](https://underwaternoise.atlanttic.uvigo.es/) requires a full-access request. The inspected [UniqueShip release page](https://uniqueshipdata.org/) lacked an explicit dataset license; AIS-negative labels do not guarantee acoustic silence. [ONC's policy](https://www.oceannetworks.ca/data/data-policy/) permits CC-BY 4.0 for solely ONC-owned data; partner terms differ.

The executed PORTIA cohort and access amendment supersede these initial candidates: see [data audit](data_audit.md). Human real-event auditing is unavailable. Real AIS presence, synthetic supports and semi-synthetic insertion labels remain separate.
