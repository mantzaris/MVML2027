\section{Controlled Representation Study}

This companion study provides controlled reference tests for choosing acoustic representations. Fully synthetic scenes comprise colored ambient noise and zero, one or two harmonic, amplitude-modulated or chirped sources. Exact construction labels identify received supports, including bounded multipath delay. Overlapping source supports are merged into the union of activity for temporal scoring. The separately trained temporal spectral CNN evaluates fully/semi-synthetic activity unions, treating overlapping sources as one scored interval.\par

The focused representation study uses three-second controlled clips and fixed detection heads for STFT, STFT plus wavelets, STFT plus bounded HHT, and all views. It separates training/development/test generation identities and a held-out signal family. Presence AP measures recording-level discrimination; temporal AP measures interval detection. The bounded HHT branch supplies an explicitly exploratory comparison.\par

\section{HHT and Wavelet Numerical Validity}

Numerical checks distinguish reconstruction accuracy from valid extracted modes. The bounded GPU EMD approximation uses up to six modes and ten sifts, piecewise-linear envelopes and masked instantaneous-frequency summaries. It is evaluated as a piecewise-linear approximation to classical cubic-spline EMD. Noisy-scene convergence failures define its exploratory scope.\par

Preserved development traces guided a reproducible controller correction before test evaluation. The unconstrained replay had 50.0\% valid actions across 4,220 actions from 2,110 clip-seed records (including partial runs). Requests for already observed STFT after wavelet acquisition identified the integration defect. Finite legal-JSON token-trie decoding then enforced schema validity by construction, retaining the independent parser. EOS is required and observed tools are excluded; actions are accepted without favorable-outcome retries. The 160-state GPU fixture checks this integration property. All 3,600 test clip-seed paths were wavelet, Fourier, then verify, providing an explicit fixed-sequence reference; generated evidence entered final scoring after tool acquisition.\par

Experiment recovery uses project-local atomic checkpoints, checksummed generation metadata, a hash-chained ledger and verified prediction shards. Restarting recomputes unfinished work and preserves completed outputs. Source/configuration/data fingerprints guard against accidental resume under a different experiment.\par

All code, data, caches, models, figures, reports and restart artifacts remain inside the new MVML2027 submission directory. The earlier submission is unchanged. Large raw data and checkpoints remain outside version control; no publication or submission is performed by generating these drafts.\par

The controlled study supplies tested baselines and repeatable checks for acoustic representation design. Across three detector seeds, STFT reached mean presence AP 0.995 on in-family test scenes and 0.880 on the held-out generated family, quantifying sensitivity to changed conditions. Missing-input tests extend this comparison to incomplete evidence. Numerical checks distinguished accurate reconstruction from converged modes, keeping the high-scoring bounded HHT approximation exploratory. Together, these results make representation choice and numerical reliability separately assessable. Synthetic results describe the specified generation families and activity labels. Real-data comparisons describe vessel-tracking presence under artificial class balance, a fixed generator seed, one deployment and one connected test component; AP, precision and calibration are cohort-specific.\par
