\drafttitle{Multi-Representation Underwater Acoustic Object Detection with Generative AI Reasoning Agents}

\begin{center}Anonymous authors\end{center}

{\fontsize{10}{11.5}\selectfont\noindent \textbf{\textit{Abstract - }}Consider a harbour monitor deciding whether a noisy underwater recording contains a vessel. Fourier analysis reveals which tones are present, spectrograms show when they occur, and wavelets describe changes across time scales. We present a multi-representation protocol for testing whether generative AI can turn these different views into useful detection evidence. A language-model agent selects tools from numerical detector summaries; a separate convolutional network analyses two-dimensional spectrograms. The agent can request replacement of a short recording interval with generated background. A proposed cross-view score compares this replacement with an approximately matched disturbance applied to the same interval, testing the intervention relative to an editing control. This comparison does not establish physical source removal. Real recordings test vessel-presence scoring, while separate synthetic and real-excerpt insertion studies examine representations and event timing. On 1,200 deliberately balanced PORTIA test clips labelled using vessel-tracking records, average precision (AP), computed from mean-seed probabilities, was 0.5738 for the agent and 0.5906 for the development-selected wavelet detector. The agent and fixed verification had the same ensemble AP; the agent required 7.02 times as much warm batch-processing time. Every agent test path acquired all primary views and verified last, demonstrating no adaptive selection. The bounded Hilbert-Huang approximation remains exploratory after numerical failures, and repeated vessels connect all five test days, preventing independent-component uncertainty estimation. The contribution is a controlled evaluation of representation choice, generative intervention and agent control, with practical checks for deciding whether each added component justifies its computational cost.\par}

{\fontsize{9}{11}\selectfont\noindent \textbf{Keywords:} underwater acoustics; object detection; generative AI; reasoning agents; signal representations; spectrograms; wavelets; Hilbert-Huang transform\par}

\section{Introduction}

Fourier spectra, spectrograms and wavelets expose different frequency and time structure in the same underwater waveform. We compare their individual and fused detection performance and test bounded tool selection across these representations, with generative verification as an additional probe (Fig.~\ref{fig:1}). The controller receives numerical head outputs, not images; a separate CNN processes two-dimensional log-mel spectrograms. Detection here means AIS-linked window presence.\par

\section{Related Work and Method}

Physics-aware audio-language frameworks already combine complementary acoustic representations with generated reports \cite{signals1,signals2}. Underwater audio-language benchmarks test waveform dependence \cite{uabench}, and generative augmentation addresses data scarcity \cite{physicsgen}. Wavelet front ends \cite{waveletship} and the HHT decomposition \cite{huang1998} are established methods. Speech-to-ocean transfer \cite{speechocean} motivates a pretrained baseline. The candidate contribution is the paired intervention and tool-selection protocol.\par

\subsection{Acoustic representations and detection}

Native audio is preserved; channel 0 is CUDA-resampled to 16 kHz. Fourier, multi-resolution STFT and analytic Morlet views provide 32, 64 and 56 features. Scaling uses training data only. The 32-feature bounded linear-envelope HHT approximation is exploratory after its numerical failure.\par

\begin{equation}\label{eq:fourier}
X[k]=\sum_{n=0}^{N-1}x[n]e^{-j2\pi kn/N}
\end{equation}

\begin{equation}\label{eq:stft}
S(m,k)=\left|\sum_n x[n]w[n-mH]e^{-j2\pi kn/N}\right|^2
\end{equation}

\begin{equation}\label{eq:hht}
x(t)=\sum_q c_q(t)+r(t),\quad f_q(t)=\frac{1}{2\pi}\frac{d\phi_q(t)}{dt}
\end{equation}

The primary verification replaces the fixed central 1.5 seconds [0.75, 2.25] of each three-second clip while preserving exterior context. Scoring remains window presence, not source deletion or localization. Baselines include feature heads, a 2D log-mel spectrogram CNN, and frozen speech-ASR pretrained/fine-tuned facebook/wav2vec2-base-960h \cite{wav2vec2}, mean/SD pooled into 1,536 features.\par

\subsection{Generative replacement and paired control}

A conditional waveform flow \cite{flowmatching} learns background completion. For editable mask \(M\), background \(b\), observation \(u\) and Gaussian \(z\), training uses \(y(t)=M[(1-t)z+tb]+(1-M)u\). A same-support sham approximately matches perturbation energy and coarse spectrum: after masking, RMS mismatch must be below 0.05 and eight-band normalized-power \(L_1\) error below 0.2. Other engineering gates check finite features, exterior invariance and amplitude. Rejection returns the base score. The full-record null is context-unconditional except for observed-RMS scaling, not a physical counterfactual.\par

\begin{equation}\label{eq:delta}
\delta_{vk}=[L_v(x)-L_v(x^{-k})]-[L_v(x)-L_v(x^{0k})]
\end{equation}

\begin{equation}\label{eq:score}
V=\mathrm{median}_{v,k}(\delta_{vk})-\lambda\,\mathrm{MAD}_{v,k}(\delta_{vk})-\gamma R
\end{equation}

\(L\) is a view-head logit clipped to \([-8,8]\). We use \(K=4\) draws, 8 Euler steps, \(\lambda=0.5\) and \(\gamma=0.1\); medians use the lower central order statistic. \(R\) measures exterior change and boundary perturbation. Nonnegative logistic calibration combines base evidence with \(V\). Views are correlated; this acoustic formulation combines familiar robust aggregation and calibration, whose utility must be established empirically.\par

\section{Data and Experimental Protocol}

The real study uses a custom PORTIA v2 cohort \cite{portia}, not the official benchmark split. Its labels reflect AIS-linked vessel co-occurrence, not human judgments of audibility. Single-vessel-task positives and binary-task negatives are combined after excluding 2,388 window IDs with conflicting cross-task labels. Days are allocated before learning; vessel IDs that cross allocated partitions are reserved by test/calibration/development/train priority. A 60-second temporal guard separates partitions. The test cohort is deliberately 600 positive and 600 background clips, not deployment prevalence: AP/precision and probability calibration are cohort-specific.\par

Repeated vessel identities connect all five test days into one dependence component. Neither 1,200 clips nor five days are independent deployment replicates. AIS co-occurrence supplies no human audibility judgment or natural acoustic-event boundaries.\par

\subsection{Models, controller and controls}

Three detector seeds are evaluated with one shared generator trained at seed 17. The frozen non-thinking Qwen3-4B-Instruct-2507 \cite{qwen} tool controller runs wholly on the RTX 5000 Ada. It starts from STFT evidence and can acquire Fourier/wavelet evidence, verify, or stop within three additional actions. A finite token trie masks generation to legal JSON actions and enumerated reasons for the current candidate and tool budget; the model greedily chooses legal prefixes. The strict parser remains an independent check. Schema validity is enforced by construction, not evidence of acoustic correctness. The LLM cannot overwrite detector probabilities.\par

{\fontsize{9}{11}\selectfont\noindent The archived unconstrained development run achieved only 50.0\% action validity. This engineering failure motivated the decoding amendment before test evaluation; failed traces and source snapshots remain preserved.\par}

Controls include acoustic/foundation baselines, fixed and heuristic verification, the agent without generation, matched \(V=0\) score controls and component ablations.\par

\subsection{Outcomes and uncertainty}

The real primary endpoint is AP against AIS-presence labels. Thresholds are selected on calibration data for a target empirical negative-clip FPR; test recall and FPR are both reported. AP, AUROC and Brier score are computed for every retained record before any referral. Controlled temporal AP uses one-to-one matching at stated IoU thresholds. No primary confidence interval is reported for the single day-vessel component. An optional 2,000-draw paired day-bootstrap interval is nonconfirmatory sensitivity analysis because vessels recur across days. Detector-seed variability is descriptive.\par

\section{Mechanism and Component Ablations}

Figure~\ref{fig:4} reports the continuous-score controls. Keeping \(V\) instead of setting it to zero changed ensemble AP by -0.0257 for fixed verification and -0.0257 for the agent. All three detector-seed differences were negative in each control family. These descriptive contrasts preserve queries, validity and calibration routing.\par

{\fontsize{9}{11}\selectfont\noindent All 2,205 development clip-seed decisions followed wavelet then fourier then verify. The observed controller therefore behaved as a fixed acquisition sequence; these traces do not establish evidence-dependent adaptation or a reasoning benefit.\par}

{\fontsize{9}{11}\selectfont\noindent All 3,600 held-out test clip-seed decisions acquired all three views and requested verification. Every audited path was wavelet, Fourier, then verify. Verification was the final action, so generated evidence informed no subsequent tool choice. The observed test policy did not perform adaptive tool selection.\par}

The fixed and agent \(V=0\) controls preserve base logits, acquired views, queries, validity masks, fitting rows and the same two-input positive calibration procedure. Only the entire continuous score \(V\) is set to zero. The agent control preserves the original verification-enabled actions, rather than rerunning the no-generation controller. \(V=0\) removes contrast, dispersion and boundary penalty together, rather than isolating \(\delta\) alone.\par

\subsection{Counterfactual interpretation}

The intervention is computational. Its sham is constrained to the same support and matched in perturbation energy, but nuisance edits can still change target detectability. The measured paired controls test component utility, not strict physical counterfactual identification. Invalid or unavailable verification returns the base detector output and remains in the denominator.\par

\subsection{HHT numerical failure}

HHT reconstruction and a simple-tone check passed, but noisy modes frequently failed extrema or convergence checks. The recorded fractions are 95.8\% for the three-second fixture and 100.0\% for the ten-second fixture. The exploratory HHT head nevertheless reached mean-seed AP 0.6929. Its descriptive accuracy does not validate the decomposition or promote it into the primary analysis.\par

\section{Compute, Reproducibility and Limitations}

\draftfigure{figure5_accuracy_compute}{3.1}{Mean detector-seed test AP and actual seed 17 live cost on 32 calibration clips at batch 32, with three warmed passes; horizontal bars show their range, not a confidence interval. Five timed methods include heuristic verification. Model loading is excluded and separately recorded; memory is allocated GPU peak. This measured-method comparison is not an overall cost frontier over unmeasured stronger baselines.}{5}

The agent cost 346.9 ms/clip, versus 49.4 for fixed verification, 39.0 for the heuristic, 7.1 for numeric fusion and 299.4 without generation. The agent/fixed cost ratio was 7.02; allocated agent peak was 11.37 GiB. These are warm batch-throughput measurements, not single-request latency.\par

All substantial transforms, fitting and inference use the 32 GB RTX 5000 Ada, selected by UUID. CPU orchestration, I/O, statistical reporting and a small independent spline-reference fixture are incidental. The Thunderbolt connection makes transfer-inclusive measurement essential. Live timings include decoding, transfer, GPU transforms, requested generation, controller calls, classification and frozen calibration. Full primary transform recomputation and unqueried canonical generation companions are charged; no transform-savings claim is made.\par

Checkpoints preserve model, optimizer, scheduler, random states, configuration fingerprints and the next-batch cursor. Atomic file replacement, fsync, checksum validation and a prior generation support interrupted-run recovery. A separate-process CUDA fixture reproduced the next optimizer step exactly and recovered from a corrupted latest checkpoint copy. This does not protect against storage destruction or establish bitwise reproducibility of every final research kernel.\par

The strongest limitations are AIS proxies, artificial class balance, one test dependence component, cohort construction, a shared generator seed, a single external GPU/system, and controlled rather than independently annotated real temporal intervals. An agent's rationale is not ground truth. Any gains must be attributed only to contrasts supported by the saved outputs.\par

\section{Conclusion}

The study offers a reproducible protocol for testing how different views of an underwater recording support detection. It combines representation-specific evidence, a nuisance-adjusted verification score, constrained tool selection and measured computation. In a harbour-monitoring example, a falling vessel score after generated replacement must be compared with the effect of a control edit: both can disturb useful sound. Their contrast tests sensitivity without establishing physical source removal.\par

On the balanced real-data cohort, ensemble AP was 0.5738 for the agent and 0.5906 for the development-selected wavelet detector. Agent and fixed verification had the same ensemble AP, but the agent required 7.02 times as much warm batch-processing time. Every test path acquired all primary views and verified last, like an inspector following a fixed checklist. Generated evidence informed no later tool choice. The continuous verification score reduced AP by 0.0257 against its matched zero-score control. Added complexity did not improve detection or selective acquisition in this execution.\par

The protocol helps identify which representations and AI components merit further development. Controlled-data studies and HHT checks also distinguish predictive accuracy from evidence quality. Vessel-tracking proxies and one connected test component limit generalization. Progress requires independently annotated acoustic events, additional deployments and evidence-dependent choices whose benefits survive matched controls and measured cost.\par
